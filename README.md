# Preflight

An open-source Python firewall that simulates every action an LLM-driven robot proposes, and blocks the ones whose physical outcome breaks a safety rule.

Work in progress toward v0.1.

## Development

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
.venv/bin/pytest
```

## Scenes

`scenes/kitchen.xml` is a MuJoCo scene: a table with a Franka Panda, a static human standing at the table with a hand on it, a hot cup, a knife, a plate and a sink. It is generated by `scenes/build_kitchen.py`; edit the builder and rerun it rather than editing the XML by hand.

```sh
.venv/bin/python scenes/build_kitchen.py               # regenerate scenes/kitchen.xml
.venv/bin/python scenes/view.py                        # look at it, starting from the home pose
```

On macOS:
- Use `python`, not `mjpython`. With MuJoCo 4.0.1, `mjpython` creates the window off the main thread and AppKit refuses ("RuntimeError: Caught an unknown exception!").
- Use `scenes/view.py` rather than `python -m mujoco.viewer --mjcf scenes/kitchen.xml`. The viewer moves the working directory into `Python.app` while it starts up, so a relative path fails with "ParseXML: Error opening file". If you call the viewer directly, pass an absolute path.

Third-party models in `assets/` are listed in [assets/VENDORED.md](assets/VENDORED.md).

## Replay

The firewall can write each decision to an audit log (`AuditLog` in `preflight/audit/log.py`). To see one decision again in the MuJoCo viewer:

```sh
.venv/bin/preflight replay audit.jsonl --id 2
```

The command prints the verdict and the findings. Then it plays the checked trajectory. For a blocked call, this is the motion that did not run.

## MCP server

`preflight serve --mcp` gives an MCP client, such as Claude Code or Claude Desktop, the tools of the guarded robot. The firewall checks each call before the robot moves.

```sh
.venv/bin/python -m pip install -e '.[mcp]'
claude mcp add preflight -- "$PWD/.venv/bin/preflight" serve --mcp --rules "$PWD/scenes/kitchen_rules.yaml"
```

[examples/mcp_demo.md](examples/mcp_demo.md) shows the options, the Claude Desktop setup and an example session.
